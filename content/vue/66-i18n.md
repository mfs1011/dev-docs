# 66 — Ko'p tillilik (i18n)

[← Oldingi: Xavfsizlik](65-xavfsizlik.md) · [Mundarija](README.md) · [Keyingi: Deploy →](67-deploy.md)

## Tushuncha

Ko'p tillilik uchta masaladan iborat va ular ko'pincha chalkashtiriladi:

1. **Tarjima** — matnlarni almashtirish;
2. **Formatlash** — sana, son, valyuta, ko'plik shakllari;
3. **Marshrutlash va SEO** — `/uz/...`, `/ru/...`, `hreflang` (61-bob).

O'zbek tili uchun alohida masala: lotin va kirill yozuvlari (`uz-Latn`, `uz-Cyrl`) — bu ikki til emas, bir tilning ikki yozuvi, lekin texnik jihatdan alohida "locale" sifatida ishlanadi.

## Kod: vue-i18n

```bash
npm i vue-i18n@11
```

```js
// i18n/index.js
import { createI18n } from 'vue-i18n'
import uz from './locales/uz.json'

export const i18n = createI18n({
  legacy: false,                       // Composition API rejimi
  locale: 'uz',
  fallbackLocale: 'uz',
  messages: { uz },
})
```

```js
// main.js
app.use(i18n)
```

```json
// i18n/locales/uz.json
{
  "nav": { "home": "Bosh sahifa", "products": "Mahsulotlar" },
  "cart": {
    "title": "Savat",
    "empty": "Savat bo'sh",
    "items": "Savatda {count} ta mahsulot",
    "total": "Jami: {amount}"
  },
  "auth": { "login": "Kirish", "logout": "Chiqish" }
}
```

```vue
<script setup>
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n()
</script>

<template>
    <h1>{{ t('cart.title') }}</h1>
    <p>{{ t('cart.items', { count: items.length }) }}</p>

    <select v-model="locale">
        <option value="uz">O'zbekcha</option>
        <option value="ru">Русский</option>
        <option value="en">English</option>
    </select>
</template>
```

## Kod: ko'plik shakllari

```json
{
  "products": "Mahsulot yo'q | {n} ta mahsulot | {n} ta mahsulot"
}
```

```vue
<p>{{ t('products', items.length) }}</p>
```

Tillar ko'plik qoidalari bilan farq qiladi: ingliz tilida 2 shakl, rus tilida 3 (1, 2–4, 5+), o'zbek tilida amalda 1 shakl yetarli. `vue-i18n` `Intl.PluralRules` ga tayanadi, lekin murakkab tillar uchun shakllar tartibini tekshiring.

## Kod: formatlash

```js
const { d, n } = useI18n()
```

```vue
<p>{{ d(order.createdAt, 'short') }}</p>
<p>{{ n(product.price, 'currency') }}</p>
```

```js
export const i18n = createI18n({
  // ...
  datetimeFormats: {
    uz: {
      short: { year: 'numeric', month: 'long', day: 'numeric' },
      long: { dateStyle: 'full', timeStyle: 'short' },
    },
  },
  numberFormats: {
    uz: {
      currency: { style: 'currency', currency: 'UZS', maximumFractionDigits: 0 },
      percent: { style: 'percent' },
    },
  },
})
```

Kutubxonasiz ham ko'p narsa mumkin (63-bob):

```js
new Intl.NumberFormat('uz-UZ', { style: 'currency', currency: 'UZS' }).format(1250000)
// "1 250 000 UZS"

new Intl.RelativeTimeFormat('uz', { numeric: 'auto' }).format(-2, 'day')
// "2 kun oldin"

new Intl.ListFormat('uz', { style: 'long', type: 'conjunction' }).format(['olma', 'nok', 'uzum'])
```

## Kod: lazy yuklash

Barcha tarjimalarni bundle'ga solmang:

```js
const loaded = new Set(['uz'])

export async function setLocale(locale) {
  if (!loaded.has(locale)) {
    const messages = await import(`./locales/${locale}.json`)

    i18n.global.setLocaleMessage(locale, messages.default)
    loaded.add(locale)
  }

  i18n.global.locale.value = locale
  document.documentElement.lang = locale
  localStorage.setItem('locale', locale)
}
```

10 ta til × 50 KB tarjima = 500 KB. Lazy yuklash bilan foydalanuvchi faqat o'z tilini oladi.

## Kod: marshrutlash

```js
const routes = [
  {
    path: '/:locale(uz|ru|en)?',
    component: LocaleLayout,
    children: [
      { path: '', component: HomeView },
      { path: 'products', component: ProductsView },
    ],
  },
]

router.beforeEach(async (to) => {
  const locale = to.params.locale ?? detectLocale()

  if (locale !== i18n.global.locale.value) await setLocale(locale)
})

function detectLocale() {
  return (
    localStorage.getItem('locale') ??
    navigator.languages.map((l) => l.split('-')[0]).find((l) => ['uz', 'ru', 'en'].includes(l)) ??
    'uz'
  )
}
```

Nuxt'da `@nuxtjs/i18n` moduli marshrutlarni, `hreflang` teglarini va tilni aniqlashni avtomatik qiladi (59-bob).

## Kod: SSR bilan

```js
// Har so'rovga yangi i18n nusxasi (56-bob)
export function createI18nInstance(locale) {
  return createI18n({ legacy: false, locale, messages })
}
```

Tilni aniqlash serverda `Accept-Language` sarlavhasidan yoki URL'dan olinadi. Modul darajasidagi global `i18n` — SSR'da xavfli.

## Muhandislik nuqtai nazari: kalitlarni tashkil qilish

```json
// ✗ Matnning o'zi kalit sifatida
{ "Savatda 3 ta mahsulot bor": "..." }

// ✗ Juda chuqur
{ "pages": { "cart": { "components": { "list": { "title": "..." } } } } }

// ✓ Domen + kontekst
{
  "cart": { "title": "Savat", "empty": "Savat bo'sh" },
  "common": { "save": "Saqlash", "cancel": "Bekor qilish" },
  "errors": { "network": "Tarmoq xatosi" }
}
```

Qoidalar:

- Kalit **mazmunni** emas, **joyni** bildirsin (`cart.empty`, `Savat bo'sh` emas);
- Umumiy so'zlarni (`common.save`) takrorlamang;
- 3 darajadan chuqur ketmang;
- Kalitni komponent nomiga emas, domenga bog'lang — komponent qayta nomlansa tarjimalar buzilmaydi.

## Muhandislik nuqtai nazari: tarjimada matn uzunligi

Bir xil jumla turli tillarda 30–50% farq qiladi: nemis tili ingliz tilidan uzunroq, rus tili o'zbek tilidan uzunroq. Interfeys buni hisobga olishi kerak:

```css
/* ✗ Qat'iy kenglik */
.btn { width: 120px; }

/* ✓ Moslashuvchan */
.btn { min-width: 120px; padding-inline: 16px; }
```

Tekshirish usuli: eng uzun tilni (odatda nemis yoki rus) yoqib, interfeysni ko'rib chiqing. Matn kesilib qolgan joylar darhol ko'rinadi.

## Muhandislik nuqtai nazari: nima tarjima qilinmaydi

| Narsa | Tarjima |
| --- | --- |
| Interfeys matnlari | Ha |
| Xato xabarlari | Ha |
| Sana, son, valyuta | Formatlash (tarjima emas) |
| Foydalanuvchi mazmuni (izohlar, nomlar) | Yo'q |
| Server xatolarining texnik kodi | Yo'q, lekin kod bo'yicha xabar tanlanadi |
| Brend nomi | Odatda yo'q |

Server xatolari uchun eng yaxshi naqsh — **kod qaytarish**, matn emas:

```json
{ "code": "EMAIL_TAKEN", "message": "Email already taken" }
```

```js
const message = te(`errors.${error.code}`) ? t(`errors.${error.code}`) : t('errors.unknown')
```

Shunda til klientda tanlanadi va backend tarjimalarni bilishi shart emas.

## Muhandislik nuqtai nazari: kirill va lotin

O'zbek tilida ikki yozuv bor. Uch yondashuv:

1. **Ikki alohida locale** (`uz-Latn`, `uz-Cyrl`) — eng toza, lekin ikki marta tarjima;
2. **Transliteratsiya** — bitta manba (lotin), kirill avtomatik hosil qilinadi. Qoidalar deyarli bir qiymatli, shuning uchun amalda ishlaydi;
3. **Faqat lotin** — ko'p yangi loyihalar shunday qiladi.

Transliteratsiya tanlansa, uni **build vaqtida** qiling (klientda emas): natija statik JSON bo'ladi va bundle'ga qo'shimcha kod kirmaydi.

## Tipik xatolar

| Xato | Nega yomon | To'g'ri yechim |
| --- | --- | --- |
| Matnlarni komponentlarda qoldirib, keyin tarjima qilish | Keyinroq yuzlab joyni qidirish kerak | Boshidan `t()` |
| Barcha tillarni bundle'ga solish | Hajm shishadi | Lazy yuklash |
| Matnni kalit sifatida ishlatish | Matn o'zgarsa kalit ham o'zgaradi | Domen kaliti |
| `document.documentElement.lang` ni yangilamaslik | Skrinrider va brauzer noto'g'ri talaffuz qiladi | `setLocale` da yangilang |
| Sanani qo'lda formatlash | Har tilda boshqacha | `Intl.DateTimeFormat` |
| SSR'da global i18n nusxasi | Foydalanuvchilar tili aralashadi | Har so'rovga yangi nusxa |
| Qat'iy kengliklar | Uzun tarjimalar kesiladi | Moslashuvchan layout |
| `hreflang` va til URL'lari yo'q | SEO yo'qoladi | 61-bob |

## Amaliyot

1. `vue-i18n` ni ulang va uch sahifadagi matnlarni `t()` ga ko'chiring.
2. Lazy yuklashni yozing va Network panelida faqat kerakli JSON yuklanishini tekshiring.
3. `Intl.NumberFormat` bilan narxni `1 250 000 so'm` shaklida chiqaring.
4. Tilni URL'ga chiqaring (`/uz/products`) va `hreflang` teglarini qo'shing.
5. Eng uzun tilni yoqib, interfeysda kesilgan joylarni toping.
