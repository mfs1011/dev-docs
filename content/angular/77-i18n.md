# 77 — Ko'p tillilik

[← Oldingi: Xavfsizlik](76-xavfsizlik.md) · [Mundarija](README.md) · [Keyingi: Amaliy loyiha va checklist →](78-amaliy-loyiha.md)

## Tushuncha

Ko'p tillilik ikki qismdan iborat:

| Qism | Nima | Misol |
| --- | --- | --- |
| **i18n** (tarjima) | Matnlarni boshqa tilga | "Xush kelibsiz" → "Welcome" |
| **l10n** (lokalizatsiya) | Sana, raqam, valyuta, ko'plik qoidalari | `1 234 567,5` / `1,234,567.5` |

Angular'ning rasmiy yondashuvi — **`@angular/localize`**: tarjimalar **build vaqtida** kiritiladi, har til uchun alohida build. Alternativa — ish vaqtida tarjima kutubxonalari (Transloco, ngx-translate).

| | `@angular/localize` | Runtime (Transloco) |
| --- | --- | --- |
| Tarjima qachon | Build | Ish vaqtida (JSON yuklanadi) |
| Til almashish | Boshqa URL (`/uz/` → `/en/`), sahifa qayta yuklanadi | Joyida |
| Unumdorlik | Eng yaxshi — tarjima kodga "pishirilgan" | JSON yuklash + qidiruv |
| SEO, SSR | Tabiiy — har til o'z URL'i | Qo'shimcha sozlash |
| Tarjimon uchun | XLIFF — standart format (CAT vositalari) | JSON |

## Nega shunday

Build vaqtidagi tarjima — Angular kompilyatori shablonlarni allaqachon qayta ishlaydi, tarjimani ham shu yerda qo'yish runtime xarajatsiz. Narxi — til almashish qayta yuklash bilan. Ko'p saytlar uchun bu normal (foydalanuvchi tilni bir marta tanlaydi).

## Kod: o'rnatish

```bash
ng add @angular/localize
```

Tekshirildi — o'zgargan fayllar:

| Fayl | O'zgarish |
| --- | --- |
| `src/main.ts` | `/// <reference types="@angular/localize" />` |
| `tsconfig.app.json`, `tsconfig.spec.json` | `"types": ["@angular/localize"]` |
| `angular.json` | `"polyfills": ["@angular/localize/init"]` |

## Kod: matnlarni belgilash

```html
<h1 i18n="@@homeTitle">Xush kelibsiz</h1>

<p i18n="savat|Savatdagi mahsulotlar soni">
  {count(), plural, =0 {Savat bo'sh} one {{{ count() }} ta mahsulot} other {{{ count() }} ta mahsulot}}
</p>

<img src="/logo.svg" i18n-alt alt="Logotip" />
<button i18n-title title="Saqlash" i18n>Saqlash</button>
```

| Sintaksis | Ma'no |
| --- | --- |
| `i18n` | Element matnini tarjimaga |
| `i18n="@@homeTitle"` | **Barqaror id** — matn o'zgarsa ham tarjima yo'qolmaydi |
| `i18n="ma'no\|tavsif"` | Tarjimon uchun kontekst (XLIFF'da `note`) |
| `i18n-alt`, `i18n-title`, `i18n-placeholder` | Atributni tarjimaga |

### ICU: ko'plik va tanlov

**Muhim** (tekshirildi): ICU ichida `#` belgisi Angular'da **ishlamaydi** — `{count(), plural, one {# ta mahsulot}}` sahifada so'zma-so'z "# ta mahsulot" chiqardi. Qiymat — interpolatsiya bilan: `{{ count() }} ta mahsulot`. Shunda "3 ta mahsulot" / "3 items".

```html
<span i18n>{gender(), select, male {U kirdi} female {U kirdi} other {Foydalanuvchi kirdi}}</span>
```

Ko'plik qoidalari tilga qarab: o'zbek tilida `one` / `other`, rus tilida `one` / `few` / `many` / `other`. Tarjimon o'z tilining shakllarini yozadi.

### Koddagi matnlar — `$localize`

```ts
protected readonly greeting = $localize`:@@greet:Salom, ${this.name()}:name:!`;

this.toast.show($localize`:@@cartAdded:Savatga qo'shildi`);
```

`:@@id:` — id, `${x}:name:` — o'zgaruvchi nomi (tarjimon ko'radi). Toast, `title`, xato xabarlari — hammasi tarjimaga.

## Kod: chiqarish va tarjima

```bash
ng extract-i18n --output-path src/locale
```

Tekshirildi — `src/locale/messages.xlf` (4 ta xabar):

```xml
<file source-language="en-US" ...>          <!-- sukut! -->
  <trans-unit id="homeTitle">
    <source>Xush kelibsiz</source>
  </trans-unit>
  <trans-unit id="5012495686999403326">
    <source>{VAR_PLURAL, plural, =0 {Savat bo'sh} one {<x id="INTERPOLATION"/> ta mahsulot} ...}</source>
    <note from="description">Savatdagi mahsulotlar soni</note>
    <note from="meaning">savat</note>
  </trans-unit>
  <trans-unit id="greet">
    <source>Salom, <x id="name" .../>!</source>
  </trans-unit>
```

`source-language="en-US"` — sukut. Manba tili o'zbekcha bo'lsa, `angular.json` da `sourceLocale` ni ko'rsating (aks holda sana/raqam formatlari ham `en-US` bo'ladi).

Tarjima fayli — nusxa + `<target>`:

```xml
<!-- src/locale/messages.en.xlf -->
<file source-language="uz" target-language="en">
  <trans-unit id="homeTitle">
    <source>Xush kelibsiz</source>
    <target>Welcome</target>
  </trans-unit>
```

Id'siz xabarlar (`5012495686999403326`) — matndan hisoblangan hash: manba matni o'zgarsa, id o'zgaradi va tarjima "yo'qoladi". Muhim matnlarga `@@id`.

## Kod: build

```json
// angular.json → projects.<nom>
"i18n": {
  "sourceLocale": "uz",
  "locales": {
    "en": "src/locale/messages.en.xlf",
    "ru": "src/locale/messages.ru.xlf"
  }
},
"architect": {
  "build": {
    "options": { "localize": true }
  }
}
```

Tekshirildi — `ng build` natijasi:

```
dist/<nom>/browser/
├── uz/index.html     <html lang="uz">  <base href="/uz/">
└── en/index.html     <html lang="en">  <base href="/en/">
```

Brauzerda (Playwright bilan):

| | uz | en |
| --- | --- | --- |
| Sarlavha | Xush kelibsiz | Welcome |
| Ko'plik | 3 ta mahsulot | 3 items |
| `date: 'longDate'` | 30-sentabr, 2026 | September 30, 2026 |
| `number` | 1 234 567,5 | 1,234,567.5 |
| `currency: 'UZS'` | 99 000,00 soʻm | UZS99,000.00 |
| `$localize` | Salom, Ali! | Hello, Ali! |

Locale ma'lumotlari (sana, raqam formatlari) **avtomatik** — har build o'z tilini oladi, `registerLocaleData` shart emas.

`ng serve` da bitta til: `ng serve --configuration=en` (configurations'da `"localize": ["en"]`).

### Tarjima yetishmasa

| Holat | Natija (tekshirildi) |
| --- | --- |
| `trans-unit` bor, `<target>` yo'q | Manba matni ("Logotip") — **ogohlantirishsiz** |
| `trans-unit` umuman yo'q | `WARNING: No translation found for "…" ("Logotip").` + manba matni |

CI'da qat'iy bo'lish uchun:

```json
"options": { "i18nMissingTranslation": "error" }
```

## Kod: deploy va til tanlash

```nginx
location ~ ^/(uz|en|ru)/ {
  try_files $uri /$1/index.html;
}
location = / {
  # Brauzer tiliga qarab
  if ($http_accept_language ~* "^en") { return 302 /en/; }
  return 302 /uz/;
}
```

Til almashtirgich — oddiy havolalar:

```html
<a href="/uz/" hreflang="uz" lang="uz">O'zbekcha</a>
<a href="/en/" hreflang="en" lang="en">English</a>
```

`routerLink` emas — boshqa build, to'liq yuklash kerak. SEO uchun `<link rel="alternate" hreflang="en" href="https://shop.uz/en/">`.

## Muhandislik nuqtai nazari

**Boshidan i18n'ga tayyor bo'ling**, hatto bitta til bo'lsa ham:

- Matnlarni kodga "qotirib" yozmang — `i18n` belgisi arzon, keyin 500 ta shablonni aylanish qimmat.
- Sana/raqam — **har doim** pipe'lar orqali (`DatePipe`, `DecimalPipe`), `toString()` bilan emas.
- Matnni qismlarga bo'lmang: `"Sizda " + n + " ta xabar"` — boshqa tillarda so'z tartibi boshqacha. ICU ishlating.
- Tugma va maydonlarni matn uzayishiga tayyorlang (nemischa +30%).
- RTL (arab tili) kerak bo'lsa — `dir`, CSS logical properties (`margin-inline-start`).

Serverdan kelgan kontent (mahsulot nomlari) — `@angular/localize` emas, backend'da ko'p tilli maydonlar.

## Tipik xatolar

| Xato | Oqibat | To'g'ri yo'l |
| --- | --- | --- |
| ICU'da `#` | So'zma-so'z "#" chiqadi | `{{ count() }}` |
| `sourceLocale` ko'rsatilmagan | Manba `en-US` — formatlar noto'g'ri | `"sourceLocale": "uz"` |
| Muhim matnlarda `@@id` yo'q | Matn tuzatilsa tarjima yo'qoladi | Barqaror id |
| Koddagi matnlar (`toast('Saqlandi')`) | Tarjimaga kirmaydi | `$localize` |
| Qismlarga bo'lingan jumlalar | Tarjima qilib bo'lmaydi | Butun jumla + ICU |
| Tarjima yetishmasligi CI'da sezilmaydi | Aralash tilli sahifa | `i18nMissingTranslation: "error"` |
| Til almashtirishda `routerLink` | Build almashmaydi | Oddiy `<a href>` |

## Amaliyot

1. `ng add @angular/localize`; bosh sahifa matnlariga `i18n="@@..."` qo'shing.
2. Savat hisoblagichini ICU `plural` bilan — avval `#` bilan yozib natijani ko'ring, keyin tuzating.
3. Toast xabarlarini `$localize` ga o'tkazing.
4. `ng extract-i18n`, `sourceLocale: "uz"`, inglizcha tarjima fayli.
5. `localize: true` bilan build; ikki til papkasini va sana/raqam formatlarini solishtiring.
6. Bitta `trans-unit` ni o'chirib ogohlantirishni ko'ring; `i18nMissingTranslation: "error"` ni yoqing.
