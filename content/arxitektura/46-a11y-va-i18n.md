# 46 — Erishimlilik va ko'p tillilik

[← Oldingi: Formalar arxitekturasi](45-formalar.md) · [Mundarija](README.md) · [Keyingi: Unumdorlik byudjetlari →](47-unumdorlik-byudjetlari.md)

## Tushuncha

Erishimlilik (a11y) va ko'p tillilik (i18n) — ikkalasi ham **"keyin qo'shamiz"** deb qoldiriladigan va keyin eng qimmatga tushadigan sifat atributlari. Sabab bir xil: ular alohida feature emas, **har bir** komponent, matn va sahifaga tegishli ko'ndalang talab.

| | Erishimlilik | Ko'p tillilik |
| --- | --- | --- |
| Nima | Hamma foydalana olsin: ekran o'quvchi, klaviatura, kattalashtirish | Bir nechta til va mintaqa formatlari |
| Standart | WCAG 2.2 AA | ICU, CLDR, BCP 47 |
| Keyinga qoldirish narxi | Har komponentni qayta ko'rish | Har matnni qidirish va almashtirish |

## Nega shunday

Keyinroq qo'shish narxi — **chiziqli emas**: 10 komponentli ilovada a11y — bir kun, 500 komponentli ilovada — oylar. Shuning uchun ular **arxitektura qarori** — dizayn tizimi (43-bob) va kodlash qoidalari darajasida.

Erishimlilik ko'p mamlakatlarda qonuniy talab (EU Accessibility Act, 2025) — ommaviy xizmatlar uchun.

## Psevdokod: a11y — qatlamlar bo'yicha

```text
Dizayn tizimi (bir marta, hamma uchun):
  - komponentlar: to'g'ri rol, klaviatura, fokus (headless primitivlar — Aria/Radix)
  - tokenlar: kontrast AA, :focus-visible uslubi
Ilova darajasi:
  - sahifa: <main>, sarlavhalar ierarxiyasi, lang atributi
  - marshrut almashganda: fokus <main> ga + sahifa nomini e'lon qilish
  - formalar: label, aria-describedby bilan xatolar (45-bob)
Jarayon:
  - lint (template a11y qoidalari), E2E'da axe, qo'lda klaviatura/ekran o'quvchi tekshiruvi
```

## Psevdokod: i18n — boshidan to'g'ri

```text
1. Matnlar kodda "qotirilmaydi" — birinchi kundan tarjima kaliti/belgisi bilan (bitta til bo'lsa ham)
2. Jumlalar bo'linmaydi:  "Sizda " + n + " ta xabar"  ❌   →   ICU: {n, plural, one {...} other {...}}  ✅
3. Sana, son, valyuta — faqat formatlash funksiyalari orqali (Intl, framework pipe'lari)
4. Server kontenti (mahsulot nomi) — backend'da ko'p tilli maydonlar, frontend tarjimasi emas
5. Layout matn uzayishiga tayyor (+30%), RTL kerak bo'lsa — logical properties (margin-inline-start)
6. Til — URL'da (/uz/, /en/) — SEO va ulashish uchun (44-bob)
```

Build-vaqti (Angular `@angular/localize`) va runtime (i18next, vue-i18n, next-intl) — asosiy tanlov:

| | Build vaqtida | Ish vaqtida |
| --- | --- | --- |
| Tezlik | Eng yaxshi | JSON yuklash |
| Til almashtirish | Qayta yuklash, boshqa URL | Joyida |
| SSR/SEO | Tabiiy | Sozlash kerak |

## Trade-off

| Qaror | Yutuq | Narx |
| --- | --- | --- |
| A11y dizayn tizimida | Bir marta to'g'ri, hamma joyda | Boshlang'ich investitsiya |
| A11y har sahifada qo'lda | — | Nomuvofiq, qimmat |
| I18n boshidan (bitta til bo'lsa ham) | Keyin til qo'shish arzon | Ozgina qo'shimcha kod |
| I18n keyinroq | Hozir tez | Har matnni qidirish, jumlalarni qayta yozish |

## Tipik xatolar

| Xato | Nega yomon | To'g'ri yo'l |
| --- | --- | --- |
| `<div (click)>` tugma | Klaviatura va ekran o'quvchi uchun yo'q | `<button>`, headless primitivlar |
| `outline: none` | Fokus ko'rinmaydi | `:focus-visible` token |
| Marshrut almashishi e'lon qilinmaydi | Ekran o'quvchi foydalanuvchisi adashadi | Fokus + live region |
| Matnlar kodda qotirilgan | Tarjima — qidiruv loyihasi | Birinchi kundan kalitlar |
| Jumlani qismlarga bo'lish | Boshqa tillarda tartib boshqa | ICU |
| `toString()` bilan sana/son | Lokal format yo'q | Intl / pipe'lar |

## Amaliyot

1. Asosiy oqimni faqat klaviatura bilan bajaring — qayerda to'xtadingiz?
2. Dizayn tizimi komponentlaringizni a11y bo'yicha tekshiring (axe, lint).
3. Koddagi qotirilgan matnlarni sanang.
4. Qismlarga bo'lingan jumlalarni ICU'ga o'tkazing.
